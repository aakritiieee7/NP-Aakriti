# Network Pharmacology Pipeline

This repository contains a pipeline for network pharmacology analysis.

## Quick Start

To set up and run the analysis, execute the following commands in your terminal:

1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd NetworkPharmacology
    ```

3.  **Make the pipeline script executable:**
    ```bash
    chmod +x run_pipeline.sh
    ```

4.  **Run the pipeline:**
    ```bash
    ./run_pipeline.sh
    ```

This will execute the entire workflow, from data processing to generating the final results.
